Poseidon 3090

Pearl mining, perfected for one card.

Poseidon 3090 is mining software built from scratch for a single purpose: mining Pearl (PRL) on the NVIDIA RTX 3090. No multi-algo bloat. No kernels ported from other cards. Every decision serves one scoreboard — pool-accepted hashrate per watt, measured in public.

Why another Pearl miner?

Because every incumbent is a compromise — and a single-purpose tool doesn't have to be.

Pure Pearl

One coin, one algorithm: pearlhash. No algo-switching machinery, no dead code paths for coins you'll never mine on this card.

Pure 3090

The kernel is tuned for Ampere sm_86 from the first line — 82 SMs, tensor cores, GDDR6X behaviour — not adapted down from Blackwell or up from Turing.

The GPU never stalls

Proof and Merkle construction and job switches run async on CPU threads while the GPU keeps hashing. Stale shares are counted, published, and engineered down.

Real autotune

Per-card measured profiles, picked by efficiency with a hashrate floor — never trading 20% more power for 1% more hashrate.

Dev fee — 2%, in the open

Poseidon charges a 2% dev fee, the standard way miner dev fees work — the same mechanism as SRBMiner, OneZeroMiner, lolMiner and WildRig: every so often the miner switches to the dev pool and mines to the dev wallet for 2% of the time, then switches back to your pool and your wallet. Fee rounds are announced in the log and the stats API while they run, and a round is skipped rather than ever interrupting your mining. No hidden fee, ever.

Where it stands

Built in public, claimed only when proven — and improved daily: higher hashrate, lower power draw, everything better, one measured bench at a time.

Framework

Done — stratum core with stale-share accounting, autotune selection, telemetry API, OC profiles and the fee slicer, all unit-tested.

Baselines

In progress — SRBMiner and OneZeroMiner measured on a real 3090, on the test rig, per the published bench protocol.

CUDA kernel

In progress — sm_86 tensor-core GEMM plus the fused sparse preparation stage, designed from Pearl research, verified against a CPU oracle before any speed claim.
